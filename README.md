# Liga EMG

Web app for the Liga EMG — a Football Manager competition where teams are randomly drawn to players through a Champions League-style ceremony, complete with roulette animations and UCL anthem.

## Features

- **Draw Ceremony** — Roulette-style draw with animations and music
- **Standings** — Aggregated player scores across all leagues
- **Past Leagues** — Full history and standings for previous seasons
- **Coach Profiles** — Player profiles and stats

## How to Run

Open `index.html` in a browser. No build tools or server required.
